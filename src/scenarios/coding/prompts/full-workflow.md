Use the /craft coding command for a complete development workflow:

1. **Code Analysis** — automatic project structure analysis
2. **Requirement Clarification** — one question at a time
3. **Design Document** — with architect subagent
4. **Testing Strategy** — unit, E2E, both, or skip
5. **Implementation** — with approval for each change

Each stage produces documents in `.pi/craft/plans/{date}-{topic}/`
