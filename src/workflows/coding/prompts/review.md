description: Code review workflow — scope, analyze with reviewer subagent, report with severity ratings
---
Use the /craft review command for structured code review:

1. **Scope** — determine what to review (git diff, branch, files)
2. **Analyze** — reviewer subagent checks each file
3. **Report** — findings with severity ratings (🔴🟡🔵💡)

Optionally auto-fix issues with per-item approval.
